# Calculadora RPN Financeira

Calculadora financeira em RPN para iPhone, feita como página web instalável. Funciona sem internet depois do primeiro acesso.

Para instalar: abra o endereço do GitHub Pages no Safari, toque em Compartilhar e depois em "Adicionar à Tela de Início".

Os valores digitados ficam só no aparelho e não são enviados a nenhum servidor.
